# IEEE paper — An Interpretable Multi-Modal Spam Detection Framework Using Explainable AI and Machine Learning

IEEE conference format (`IEEEtran`), 7 pages.

| Path | Contents |
|---|---|
| `main.tex` | Paper source |
| `references.bib` | 35 references: the two datasets, seven foundational methods used in the paper, and 26 papers from 2024–2026 (metadata from their Crossref/DataCite DOI records; every DOI verified) |
| `tables/*.tex` | Result tables, generated by `analysis/make_tables.py` |
| `figures/` | ROC curves exported by `src/train.py` |
| `analysis/extended_analysis.py` | Statistical analysis behind the paper (CIs, McNemar/DeLong, routing, shortcut probe, faithful TreeSHAP, LIME deletion test, latency) |
| `analysis/extended_results.json` | Output of the analysis script |
| `main.pdf` | Compiled paper |
| `main_without_references.pdf` | Same paper without the reference list (for similarity checking) |

## Build

```bash
latexmk -pdf main.tex          # or: pdflatex main; bibtex main; pdflatex main; pdflatex main
```
On Overleaf, upload this folder and compile with pdfLaTeX.

## Regenerate the numbers (from the repository root)

```bash
python paper/analysis/extended_analysis.py   # ~5 min on a laptop CPU; retrains both specialists
python paper/analysis/make_tables.py
```
The retraining reproduces `reports/metrics.json` exactly. Latency figures depend on the machine.
